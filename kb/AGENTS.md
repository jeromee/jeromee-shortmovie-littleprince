# KB Guide

Durable, per-concept knowledge for *The Prince and the Rose*: characters,
world, style, vocabulary, decisions and tracked issues. Pages read as current
truth. Session state and stage tracking live in `../story-bible.md`, not here.

- One concept per page; name files by subject (`elias.md`, `royal-garden.md`).
- Every page starts with a `Status:` line (`provisional` / `decided` / `canon`).
- Cross-reference with relative links; never duplicate a description.
- Visual locks for AI prompts live in the character / world pages only.
- `index.md`: update whenever a page is created or changed.
- Raw inputs stay in `../Import/` and are never edited.
